# 所选椅子资产原点检查（2026-10-28）

结论：当前所选105种椅子的原点约定基本一致，接近资产局部包围盒中心。没有发现
“有的原点在椅脚，有的在座面”的大范围混用；现有证据不支持优先重定义原点。
包围盒中心不等于座面语义位置，这一差异应由任务几何信息表达，而不应直接判为资产错误。

## 范围与方法

输入 `data/splits/sitting_back_references_seed0.json`，83训练＋22测试，各一段reference。
划分fingerprint：`38e94cb72c84868692c6fdb23d51a812cb492ad9f5b1648351d530d26ede5ec9`。
逐文件验证manifest哈希后读取标准NPZ。全部使用原始三角网格，`object_scale`只乘一次；
当前105个资产的scale均约为0.8。

资产原点固定为local `(0,0,0)`；包围盒中心定义为原始局部网格逐轴min/max的中点，
不是对旋转后的world AABB重新取中心。后者会随物体朝向变化，不能用来判断资产原点约定。
表面中心为完整三角形面积加权质心，避免顶点密度偏差。仿真COM直接调用现有
`mass_properties`，是均匀密度网格估计，不是真实椅子的实测质量中心。

首帧世界向上方向通过 `R_object.T @ [0,0,1]` 转回local。所有105个reference首帧均为
**local +Y对应world +Z**，最大偏角仅约0.00003°。USD stage标为Z-up不等于物体网格
的实际高度轴就是local Z；评价座高时必须结合object pose。这里只验证向上轴，没有
人为声称全部资产的前向轴语义也相同。

转换器 `motion_data/converters/grail.py` 仅应用USD prim变换并保留上游object pose/scale，
没有主动减去包围盒中心或质心，因此近中心的原点约定来自上游资产。

## 座面位置：仅作候选，不当作标注

数据没有现成的语义座面中心标注。采用reference条件下的局部支撑候选：

1. 每帧把reference骨盆转换到椅子局部系，再表达在首帧重力对齐坐标中。
2. 取最低20%参考骨盆位置的中位点；不假定它已被标注为坐姿。
3. 在其水平方向16 cm×16 cm范围布置9×9条竖直射线，与原始三角网格精确相交。
4. 保留高于网格底部6 cm、低于该骨盆2 cm的最高交点，报告交点中位位置、射线覆盖率、
   高度10–90%跨度及骨盆间隙。它是局部候选，**不是整张座面的几何中心或真实接触点**。
5. 覆盖率低于50%、高度跨度超过6 cm、骨盆间隙不在4–25 cm时标记需检查。所有候选
   无论是否被额外标记，都仍是 `semantic_seat_unverified`。

全部105种资产均产生候选，其中10种有额外歧义标记。没有将它们汇总成“真实座面误差”。
斜座面、镂空座面、扶手/座面混合与reference本身的姿态都会影响估计。

## 对当前模型的含义

目前Actor获得的相对物体位置，大体就是“G1骨盆相对整把椅子中部”的关系。这一坐标
约定已经较一致，暂时没有必要为统一原点而改动动作数据、物理资产或模型输入语义。
真实任务关心的座面/靠背锚点仍可能差十几厘米，几何编码器需要从形状中提取这些信息。
若要增加任务关键点，建议后续明确标注或验证座面、靠背位置；这与纠正资产原点是两项工作。

本次几何检查不能证明原点对学习完全没有影响，也不能诊断策略失效原因；它排除了
当前所选数据中明显的原点约定混乱。未修改任何NPZ、碰撞缓存、训练代码或checkpoint。
