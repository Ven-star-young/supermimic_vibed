判定规则与注意事项

完整执行成功要求从第 0 帧一直执行到 reference 结束，没有跟踪失败或提前截断。默认严格稳定接触考察最后 1 秒：全部条件同时满足的时间 ≥95%，连续不稳定间隔 ≤0.04 秒，椅子支撑力 ≥20% 体重，滑移 ≤0.10 m/s，椅子速度 ≤0.05 m/s、角速度 ≤0.15 rad/s，骨盆相对椅子的误差 ≤0.10 m，根部朝向误差 ≤20°。使用自定义配置时以报告中的阈值为准。

默认有效支撑区域使用 reference 骨盆下方的几何代理，并非人工标注的座面；可以通过配置为每个 reference 指定椅子局部坐标系中的座面边界。接触成功因此是按明确定义的代理区域判定，不直接等同于语义上的“坐得正确”。

非完整起点或评测中断会单独标记。“随机干扰”仅指机器人初始状态扰动，不包含运行中的外部推力。页面只展示当前回放与显式加载的评测文件，不自动把少数可视化回合当成整体泛化结果。

评测具体阈值会随结果一起记录。
